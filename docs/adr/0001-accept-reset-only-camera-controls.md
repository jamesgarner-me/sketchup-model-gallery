# Accept reset-only camera controls for the MVP

The Viewer offers orbit, pan and zoom by gesture only, plus a single Reset view button. This leaves touch users who cannot do multi-finger gestures without a single-pointer way to zoom or pan (WCAG 2.2 SC 2.5.1). We accepted the gap because the owner wants a minimal toolbar and the main risk is getting lost, which Reset view solves; no WCAG level is claimed. Keyboard camera controls are kept. Revisit by adding single-pointer zoom controls if a conformance target is set.
